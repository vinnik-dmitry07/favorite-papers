## Reviewer

### Summary

This paper proposes a method for learning visual representations from synthetic data. The authors first use an LLM to generate a large corpus of image captions, then use a text-to-image model to generate multiple images for each caption. The resulting dataset is used to train a visual representation model via contrastive learning.
