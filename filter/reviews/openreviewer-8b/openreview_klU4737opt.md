# Review

## Summary
This paper discusses the challenges LLMs face in scientific discovery, particularly in formulating new axioms. The authors use Einstein's development of General Relativity as a case study, arguing that while LLMs can excel at induction and deduction, they lack the abductive "jump" from sensory experience to axioms. They propose that physically consistent, multimodal world models could help bridge this gap, enabling LLMs to make the creative leaps required for scientific invention.

## Strengths
The paper is well written and the topic is interesting.

## Weaknesses
1. The paper is a bit too philosophical for an ML conference. It would be better suited for a conference like NeurIPS Proseminar or similar. 

2. The paper lacks any concrete proposal on how to solve the problem. It is mostly a critique of current LLMs.

## Questions
1. Is there a way to test the hypothesis that LLMs can't jump? It would be interesting to test LLMs with a simplified version of the tasks Einstein had to solve, for example, the task of identifying the perihelion shift of Mercury. 

2. How would you define an artificial neural network that has a mind? 

3. How would you test whether a neural network has a mind? 

4. Can you formulate a list of axioms that a neural network "mind" should satisfy?
