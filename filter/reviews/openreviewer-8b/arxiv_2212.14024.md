# Review

## Summary
This paper proposes a new framework called Demonstrate – Search – Predict (DSP) for retrieval augmented in-context learning. The framework consists of a number of simple, composable functions for implementing in-context learning systems as deliberate programs for solving knowledge-intensive tasks. The authors implemented DSP as a Python library and used it to write programs for Open-SQuAD, HotPotQA, and QReCC, which deliver substantial gains over previous in-context learning approaches.
