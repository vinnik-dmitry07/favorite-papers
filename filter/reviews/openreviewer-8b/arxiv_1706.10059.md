# Review

## Summary
This paper proposes a reinforcement learning framework for portfolio management. The framework is based on an Ensemble of Identical Independent Evaluators (EIIE) topology, a Portfolio-Vector Memory (PVM), an Online Stochastic Batch Learning (OSBL) scheme, and a fully exploiting and explicit reward function. The framework is implemented with a Convolutional Neural Network (CNN), a basic Recurrent Neural Network (RNN), and a Long Short-Term Memory (LSTM). The framework is tested in a cryptocurrency market and outperforms other trading algorithms.

## Strengths
1.	The paper proposes a new framework for portfolio management based on reinforcement learning.

## Weaknesses
1.	The paper does not compare the proposed framework with other state-of-the-art deep reinforcement learning methods for portfolio management.
2.	The paper does not provide a detailed analysis of the performance of the framework in different market conditions.

## Questions
1.	How does the proposed framework compare with other state-of-the-art deep reinforcement learning methods for portfolio management?
2.	How does the framework perform in different market conditions? For example, how does the framework perform in a bear market or a highly volatile market?
3.	How does the framework handle the risk of the portfolio? For example, how does the framework handle the risk of bankruptcy?
