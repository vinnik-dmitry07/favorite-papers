This paper introduces Program-of-Layers (PoLar), a novel approach to dynamic inference in large language models (LLMs) that moves beyond the traditional fixed-depth forward pass. The core idea is to treat each layer of a pretrained LLM as a modular function and then dynamically assemble these layers into an execution program tailored to each specific input. This program can involve skipping layers, repeating them, or executing them in a non-sequential order, allowing for more efficient and potentially more accurate inference. The authors first use Monte Carlo Tree Search (MCTS) to explore the space of possible execution programs and demonstrate the existence of more efficient and accurate programs compared to standard inference.
