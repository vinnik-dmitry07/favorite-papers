## Summary:

This paper introduces M3M, a multilingual knowledge graph question answering (KGQA) system designed for simple, one-hop questions. The core idea behind M3M is to leverage pre-trained multilingual language models and graph embeddings to efficiently rank potential answers. The system operates by first encoding the input question using a multilingual BERT model, which produces a 768-dimensional embedding. This question embedding is then projected into separate embeddings for the subject, predicate, and object of the answer triple using three 2-layer perceptrons. The system then retrieves candidate triples from the knowledge graph by matching n-grams from the question to entity names in the graph. These candidate triples are ranked based on the cosine similarity between the question embeddings and the graph embeddings of the subject, predicate, and object. The final answer is the object of the highest-ranked triple.
