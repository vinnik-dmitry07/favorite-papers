The core idea of PSV is to leverage formal verification as a reliable correctness signal, enabling the model to iteratively improve its capabilities through a process of proposing specifications, solving them, and verifying the solutions. The proposer model generates formal specifications, which are mathematical descriptions of permitted inputs and desired output behavior for a program. The solver model then attempts to generate code that meets these specifications.
