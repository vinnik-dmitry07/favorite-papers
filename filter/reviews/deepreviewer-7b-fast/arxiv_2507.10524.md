This paper introduces Mixture-of-Recursions (MoR), a novel framework designed to enhance the efficiency of Transformer models by combining parameter sharing, adaptive computation, and memory-efficient key-value (KV) caching. The core idea behind MoR is to dynamically adjust the depth of the recursive Transformer based on the complexity of the input token, allowing for a more efficient allocation of computational resources. The method employs a lightweight router to assign each token a specific recursion depth, enabling the model to focus computational effort on the most challenging tokens. This dynamic depth selection is achieved through two primary routing strategies: expert-choice routing, which selects a subset of experts for each token, and token-choice routing, which assigns a single expert for all tokens. The authors also propose two KV caching mechanisms: recursion-wise caching, which caches KV pairs at each recursion level, and recursive caching, which reuses KV pairs across recursion steps.
